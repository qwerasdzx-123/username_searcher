安装与运行

仅需 Node.js 环境，三步即可启动本地检索服务。

📋 环境要求

⬢ Node.js 🪟 Windows / macOS / Linux

🚀 方式一：一键启动（Windows）

terminal 
双击运行 启动服务器.bat

浏览器会自动打开 http://localhost:8888

💻 方式二：手动启动

terminal 
# 终端 1 — 启动代理服务
node proxy-server.js

# 终端 2 — 启动前端服务
node simple-server.js

# 浏览器访问
open http://localhost:8888
结果解读

检索结果状态说明

每次检索会返回四种状态之一，帮助您快速判断用户名在各平台的存在情况。

✓
已注册
该用户名在此平台已存在
✗
不存在
该用户名在此平台未注册
❓
需手工验证
需要人工进一步确认结果
⚠
错误信息
请求失败或出现网络异常
